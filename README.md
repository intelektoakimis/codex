# Valentine Next.js Site 💘

A fun, cute, romantic, mobile-friendly website built with **Next.js**.

## Features
- Two playful buttons: **Yes** and **No**
- The **No** button dodges hover/click attempts
- Clicking **Yes** reveals a sweet dinner plan message for **February 14th**
- 100% client-side behavior (no backend required)

## Run locally
```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
